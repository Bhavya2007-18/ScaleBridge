## 1. 12-week build roadmap (CONFIRMED `[BP p.12]`)

| Weeks | Focus | Main deliverables | Exit condition | Implementation phase |
|---|---|---|---|---|
| 1–2 | Problem discovery | 10–15 interviews; one target process family; user workflow; public/partner data; vessel data template | Validated problem hypothesis & defined MVP workflow | Phase 0 |
| 3–4 | Core platform | Login, projects, process passport, CSV/XLSX upload, mapping, unit normalization, batch dashboard | One batch imports and visualizes correctly | Phases 1, 2, 3 |
| 5–7 | Scientific engine | Vessel profiles, engineering calculations, scale-up scenario, criterion comparison, calculation tests | Two vessels compared with traceable calculations | Phases 4, 5 |
| 8–9 | Readiness layer | Risk register, missing-data flags, equipment compatibility, validation planner | End-to-end readiness assessment generated | Phase 6, 7 |
| 10–11 | Validation | Scientific review, real dataset, independent calculation check, partner feedback, bug fixes | Reviewed prototype with documented limitations | Verification |
| 12 | Incubation pack | Demo, pitch deck, customer discovery report, milestone plan, budget, IP questions | Evidence-backed incubator submission package | Release |

## 2. 12-month company-building roadmap (CONFIRMED `[BP p.16]`)
- **Months 1–3:** Build MVP; import documented batch data; vessel profiles; calculation library; readiness report; scientific review; 10–15 interviews; recruit advisor; apply to incubator / BioE3-linked facility.
- **Months 4–6:** Validate against real process dataset; improve data quality, equipment profiles and model limits; supervised user tests; convert first design partner into paid pilot/LOI.
- **Months 7–9:** Selected read-only integrations; multi-batch comparison enhancements; passport versioning diffs; enterprise controls; 2–3 pilot customers.
- **Months 10–12:** Performance, deployment and support; expand to adjacent process types only after validation; convert pilots to annual contracts.
